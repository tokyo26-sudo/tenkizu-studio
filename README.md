# 天気図スタジオ

授業用の天気図アプリ。高気圧・低気圧・前線・台風・雲・天気記号などを地図に置いて動かし、モニタ用の「表示画面」に映せます。HTML 1ファイルで動きます。

- 操作画面：このページ
- 表示画面：URLの最後に `#display` を付けたページ（操作画面の「表示画面を開く」ボタンからも開けます）
- 2つの画面は、同じパソコンの同じブラウザで開いてください。操作画面で動かすと、表示画面がなめらかなアニメで追いかけます。

## できること
- **天気図を描く**：高気圧・低気圧・台風（進路予想・予報円・暴風域）、前線（温暖・寒冷・停滞・閉塞）、等圧線（自動／手描き）、雲（雨・雪・雷）、虹、矢印、手書きペン、文字、天気記号・イラスト
- **吹き出し**：角丸か楕円。しっぽは何本でもつけられ、先をドラッグして指したい所へ
- **モヤ**：画面に白か黒のモヤをかけ、なぞった所・囲んだ所だけ晴らして目立たせる
- **お絵かきモード**：地図のかわりに PNG・JPG の画像（天気図や衛星画像など）を背景にして、その上に描く
- **シーン**：いまの天気図をコマとして保存し、← → キーやプレゼン用リモコンでコマ送り。前のコマから次のコマへヌルヌル動きます
- **地図**：簡略地図（メルカトル／ランベルト）と地理院タイル。色・線の太さ・県境・緯線経線などを変えられます

## テレビやプロジェクタに映す
1. 操作画面の「📺 タブで開く（キャスト用）」を押す
2. 開いたタブで、Chrome の「⋮」→「キャスト…」→「タブをキャスト」
3. F キーで全画面

「表示画面を開く」ボタンはポップアップで開くので、Chrome のキャストのメニューが出ません。キャストするときは「📺 タブで開く」を使ってください。

## 保存
- 作業中の内容は、ブラウザに自動で保存されます。
- 「💾 ファイル保存」で JSON ファイルに保存し、ほかのパソコンでも読み込めます（お絵かきモードの画像も入ります）。
- 「画像保存（PNG）」で画像にできます。地図のときは 1920×1080。お絵かきモードのときは、背景の画像のところだけを切り取り、元の画像と同じかそれ以上の細かさで保存します。

## 出典
- 地図：Natural Earth、地理院タイル（国土地理院）、地球地図日本（国土地理院）
- 日本式天気記号：Wikimedia Commons（パブリックドメイン）をもとに作成
- お絵かきモードで読み込んだ画像の出典は、使う人が書いてください。操作画面の「出典」の欄に書くと、画像の右下に表示されます。
